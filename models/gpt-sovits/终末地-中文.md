# 终末地中文角色模型

## 用途与结构

同级目录 `终末地-中文/` 保存 GPT-SoVITS 中文角色音色，当前约 986.86 MiB、92 个文件，单文件最大约 164.76 MiB。当前使用洛茜模型：

```text
终末地-中文/
├─ V2ProPlus/洛茜/
├─ V4/洛茜/
└─ 素材/洛茜/
```

版本目录保存 GPT `.ckpt`、SoVITS `.pth`、默认参考音频和头像；`素材/洛茜/` 保存完整源音频。型号子目录只能继承同一角色根目录的资源，不得跨角色搜索。

## 来源

<https://www.ai-hobbyist.com/forum.php?mod=viewthread&tid=160048&extra=page%3D1&ordertype=1&mobile=no>

下载和使用前应以来源页面的许可、回复条件和版本说明为准；本仓库不分发这些模型，也不把来源链接解释为再分发授权。

## 未纳入实际文件的原因

目录含超过 100 MiB 的模型文件，不适合进入普通 Git 历史或远程代码仓库。`.gitignore` 只忽略同级实际模型目录，本说明继续由 Git 跟踪。

## 重建方法

1. 从上述来源取得 V4、V2ProPlus 及需要的参考素材，并保留原下载包。
2. 按上面的同级目录结构恢复文件；参数文件保持原名，参考音频和头像不得关联到其他角色。
3. 启动电脑服务，在 Android 模型目录中选择洛茜及目标检查点。服务必须实际加载两份权重并完成参考音频试读，成功后才会保存为当前模型；失败时会恢复此前模型。
