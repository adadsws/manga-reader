# 蔚蓝档案日语角色模型

## 用途与结构

同级目录 `蔚蓝档案-日语/` 保存 GPT-SoVITS 日语角色音色，当前约 47.19 GiB、1,097 个文件，单文件最大约 148.12 MiB。主要结构为 `v4/<组织>/<角色>/`，角色叶目录包含 GPT `.ckpt`、SoVITS `.pth`、参考音频、头像及可能存在的训练记录。

服务从 `models/gpt-sovits/` 递归发现权重；任一路径段名为 `archive` 或 `~archive` 的子树会被排除。权重、默认参考音频和头像应保持在同一角色范围内，不能跨角色继承。

## 来源

<https://www.modelscope.cn/models/aihobbyist/GPT-SoVITS_Model_Collection>

下载和使用前应以来源页面的许可、使用条件和版本说明为准；本仓库不分发这些模型，也不把来源链接解释为再分发授权。

## 未纳入实际文件的原因

目录总量远超 2 GiB，且含超过 100 MiB 的单文件，不适合进入普通 Git 历史或远程代码仓库。`.gitignore` 只忽略同级实际模型目录，本说明继续由 Git 跟踪。

## 重建方法

1. 从上述来源下载需要的角色模型，并保留原下载包及来源版本信息。
2. 解压到同级 `蔚蓝档案-日语/`，保持 `v4/<组织>/<角色>/` 层级以及权重、参考音频和头像的角色归属。
3. 启动电脑服务，在 Android 模型目录中选择目标角色。首次选择必须实际加载 GPT、SoVITS 并完成参考音频试读；失败时检查文件完整性、版本和参考音频。
