# 蔚蓝档案日奈示例模型

## 用途与放置位置

本项目只把蔚蓝档案日语角色“日奈”作为可复现的 TTS 模型示例。模型相对项目根目录放在 `models/gpt-sovits/蔚蓝档案-日语/v4/格黑娜/日奈/`，供 Android 模型目录发现并选择。

下载后的最小文件树：

```text
models/
└─ gpt-sovits/
   ├─ 蔚蓝档案-日语.md
   └─ 蔚蓝档案-日语/
      └─ v4/
         └─ 格黑娜/
            └─ 日奈/
               ├─ 日奈-e10.ckpt
               ├─ 日奈_e10_s160_l32.pth
               ├─ 【默认】風紀委員長のヒナ。私の名前は知ってると思うけど…。よろしく。.wav
               ├─ 角色头像.webp
               ├─ train.log
               └─ .source.json
```

`.source.json` 由下载脚本生成，记录来源提交、模型包校验和及解压文件清单；它与实际模型一起留在被 Git 忽略的角色目录中。

## 来源与固定版本

- 来源：[ModelScope GPT-SoVITS Model Collection](https://www.modelscope.cn/models/aihobbyist/GPT-SoVITS_Model_Collection)
- 固定提交：`afe9e5fe34392e87739b9a8445ce5028c0d2ab65`
- 上游文件：`蔚蓝档案/日语/日奈.zip`
- 文件大小：`213397439` 字节
- SHA-256：`ee1c58d9d8560229c6e0a7672d29279f68ecf9aee4683c6bc194838ee31db6e9`
- 解压后当前运行文件校验：[config/voice-model.lock.json](../../config/voice-model.lock.json)

下载和使用前应以来源页面的许可、使用条件和版本说明为准；本仓库不分发模型权重，也不把来源链接解释为再分发授权。

## 未纳入实际文件的原因

日奈模型包和其中的 GPT 权重均超过 100 MiB，不适合进入普通 Git 历史或远程代码仓库。Git 只记录本说明、下载脚本和校验信息。

## 下载与重建

使用独立下载脚本 [download_blue_archive_hina.py](../../tools/download_blue_archive_hina.py)：

```powershell
python tools/download_blue_archive_hina.py
```

脚本只请求日奈这一个 ZIP，不会下载蔚蓝档案日语全集；它先按固定提交中的 Git LFS 大小与 SHA-256 校验模型包，再检查包内包含 GPT `.ckpt`、SoVITS `.pth`、参考音频和头像，最后写入上面的角色目录。目标目录已存在时脚本会停止，不会覆盖本地模型。

安装完成后启动电脑服务，在 Android 模型目录中选择日奈。服务必须实际加载 GPT、SoVITS 并完成参考音频试读，成功后才可标为可用。
